# Design System

Tokens follow D01/D02: #004B37 dark green, #006A4E primary green, #C2185B magenta, #F3F5F4 canvas, #FFFFFF cards, #E1E7E4 borders, #E4F1EC success, #FBE7EF accent, #FCF3DC warning, #E6EEF8 info. Inter is used for interface text, Poppins for headings/KPIs, Hind Siliguri for Bangla. Header is 64px with 232px desktop sidebar; cards use 14px radius and content uses 18px 22px padding. Responsive CSS collapses the sidebar into a drawer below 760px.
