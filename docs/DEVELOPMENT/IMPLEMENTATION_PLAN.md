# MCBP-MIS Phase 0 Implementation Plan

Phase 0 establishes the static Next.js shell, bilingual foundations, demo RBAC, persistence, shared seed metrics, and D01/D02 officer dashboard. Phase 1 will implement the beneficiary lifecycle slice end to end, then payroll, training, grievances, intelligence, platform and assurance consoles in dependency order.

## Delivery order
1. Beneficiary application, verification, selection and enrollment
2. Beneficiary profile and lifecycle management
3. Payroll, reconciliation and payment simulation
4. Training, grievance and helpdesk workflows
5. Executive, GIS, AI and self-service intelligence
6. Data Hub, schemes, access and technical operations
7. Cross-route QA, bilingual parity, responsive review and acceptance evidence
